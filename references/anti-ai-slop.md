# Anti-AI-slop

The tells that make a page read as "an AI/template made this," and what to do instead.
If you catch yourself producing the left column, stop and do the right.

| Slop tell | Do instead |
|---|---|
| Everything center-aligned | Commit to a left-aligned editorial grid or a deliberate asymmetric layout. Center only when it's the point. |
| Three equal feature cards in a row | Vary weight: one hero item + smaller supporting ones, or a bento grid with intentional size differences. |
| Purple→blue gradient on white | One real accent color from a considered palette. Gradients only as a quiet background wash, never the hero's identity. |
| Every section the same vertical rhythm | Orchestrate density — a loud hero, a quiet section, a dense one. Contrast creates interest. |
| Emoji as section icons (🚀✨💡) | Real iconography (one consistent set) or no icons. Emoji is the #1 slop signal. |
| Uniform medium font weight everywhere | Push contrast: 200/300 for large display, 600/700 for emphasis. Avoid the 400-500 mush. |
| Rounded-2xl drop-shadow cards everywhere | Pick a structural language (hairline borders, or flat surfaces, or soft shadow) and hold it. Not all three. |
| Generic copy ("Empower your workflow") | Specific, concrete, human copy. Name the actual benefit. |
| Pile of unrelated stock illustrations | Real product screenshots, one photographic direction, or restrained custom graphics. |
| 6-line paragraph wrapping full width | Cap measure at ~60–75ch. Wide text is unreadable and looks unconsidered. |
| Symmetric hero: text left, image right, always | Vary it: giant type-only hero, image-led hero, off-center, mini-minimal. Don't default. |

## The two questions that catch most slop

1. **"What is the one thing this screen is remembered by?"** If you can't answer, it's generic — add a signature element (a bold type treatment, a distinctive layout, one strong visual).
2. **"Does every decision trace to a real reference or a craft rule?"** If a choice traces to nothing, it's a model default — replace it with an evidence-backed one.

## Bold ≠ busy

Pushing one axis hard (type scale, a single dominant color, one orchestrated motion moment,
an asymmetric grid) reads as confident. Pushing everything hard reads as noise. Pick the axis,
commit, keep the rest calm.
